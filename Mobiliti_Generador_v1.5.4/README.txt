MOBILITI GENERADOR v1.5.4
===========================

Requisitos:
- Windows 10/11
- Microsoft Excel instalado
- Conexion a internet (para verificar suscripcion)

Archivos incluidos:
- Mobiliti_Generador.exe  : Aplicacion principal
- config.json             : Configuracion del backend

Instrucciones:
1. Descomprime este ZIP en cualquier carpeta
2. Ejecuta Mobiliti_Generador.exe
3. Ingresa tus credenciales de login
4. Genera cotizaciones

Soporte:
- URL backend: https://verceldeploy-pied.vercel.app
