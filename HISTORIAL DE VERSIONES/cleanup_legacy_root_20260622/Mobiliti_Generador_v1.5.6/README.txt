  MOBILITI GENERADOR DE COTIZACIONES v1.5.6
================================================================================

INSTRUCCIONES DE INSTALACION
------------------------------
1. Descomprime este ZIP en cualquier carpeta (ej: Escritorio)
2. Doble clic en "Mobiliti_Generador.exe"
3. Ingresa tus credenciales ( proporcionadas por el administrador )
4. Comienza a generar cotizaciones

REQUISITOS DEL SISTEMA
----------------------
- Windows 10 o 11 (64 bits)
- Microsoft Excel instalado (requerido por xlwings)
- Conexion a internet (para verificar suscripcion y actualizaciones)

ARCHIVOS INCLUIDOS
------------------
- Mobiliti_Generador.exe    : Aplicacion principal (160 MB)
- config.json               : Configuracion del servidor backend
- README.txt                : Este archivo

ACTUALIZACIONES AUTOMATICAS
---------------------------
El programa verifica automaticamente si hay nuevas versiones disponibles.
Si aparece un dialogo de actualizacion, simplemente haz clic en "Actualizar"
y el programa se descargara e instalara la nueva version automaticamente.

SOPORTE
-------
Si tienes problemas, contacta al administrador del sistema.
